# ScholarPen 1.8.2 — 리뷰 설정과 저장 상태 판정

2026-10-26

- 답변서 언어를 영어·한국어 선택 메뉴로 변경했다.
- 새 심사 세션은 documents 아래 원고를 기본으로 모두 선택한다. 모두 선택·모두 해제 및 선택 개수를 제공하고, 다시 체크해도 목록 순서를 유지한다. exports 등에 복사한 원고는 기본 범위에서 제외한다.
- 협업 상태의 모든 갱신 시간을 본문 저장 시간과 비교하던 판정을 수정했다. 댓글과 자동 검토 메타데이터는 원고 본문 변경으로 취급하지 않는다. 저장된 본문 지문과 현재 본문을 비교한다.
- 리뷰 시작 전에 닫힌 탭을 포함해 선택한 모든 원고의 편집 상태와 저장 JSON을 동일 스키마로 대조한다. 같은 경우 기존의 오래된 미저장 표시를 갱신한다. 원본 JSON을 덮어쓰지 않는다. 실제 차이, 외부 수정, 미승인 수정 제안이 있으면 파일명을 표시하고 중단한다.
- 내보내기에 현재 파일 번호·이름·읽기/변환/그림 복사 단계·경과 시간과 오류를 표시한다. 파일 저장이 끝난 뒤 파일 목록 갱신은 별도로 수행한다. 변환 전용 편집기를 사용하고, 중첩 원고를 상대 경로로 읽는다.

## 확인한 원인과 검증 범위

사용자가 보고한 프로젝트의 원고 10개를 읽기 전용으로 대조한 결과, 모두 저장 파일과 본문이 같고 미승인 제안도 없었다. 기존 미저장 경고는 댓글·검토 상태 갱신을 본문 변경으로 간주한 잘못된 판정이었다.

QMD 10개는 이미 생성돼 있었다. 파일 저장 시각상 그림이 있는 두 장에서 약 70초 지연이 집중됐다. Google Drive 안의 그림을 별도로 읽을 때도 대기가 관찰됐다. 이는 클라우드 파일 읽기/동기화 지연과 일치하지만, 당시 실행에 단계별 로그가 없으므로 70초 전체의 원인을 확정할 수는 없다. 현재 수정은 진행 단계를 보여주고, 저장 후 목록 갱신 대기를 완료 표시와 분리한다. 클라우드 저장소 자체의 속도를 보장하지 않는다.

관련 백엔드·변환·저장 확인 테스트 85개를 함께 통과했고, 이후 빈 원고 회귀 테스트를 추가한 저장 확인 테스트 3개도 통과했다(고유 테스트 총 86개). TypeScript 검사와 브라우저의 기본 전체 선택·선택 해제·언어 선택, 내보내기 진행·오류·재시도 표시를 검증했다. 브라우저 검증은 임시 RPC로 수행했으며 새 네이티브 앱에서 실제 프로젝트 리뷰를 시작하거나 모델을 호출하지 않았다. 실제 프로젝트 본문이나 기존 설치 앱을 변경하지 않았다. 배포본은 기존과 같은 로컬용 macOS arm64 빌드다.
