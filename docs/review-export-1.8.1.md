# ScholarPen 1.8.1 — 리뷰 원고 내보내기

- 새 프로젝트를 만들 때 `reviews/` 폴더도 함께 만든다. 리뷰 세션은 기존과 같이 이 폴더에 저장된다.
- Review & Revision에서 검증이 완료된 회차를 선택하고 **원고 내보내기**를 누르면 프로젝트의 `exports/` 아래 새 폴더에 저장된다. 기본 형식은 ScholarPen JSON이며 Markdown과 Quarto도 선택할 수 있다.
- JSON은 `exports/review-<session>-r<round>-json-<id>/documents/`에 원래 바이트 그대로 저장한다. 해당 회차의 그림·자료·참고문헌도 프로젝트 구조를 유지해 복사한다.
- Markdown과 Quarto는 각 내보내기 폴더에 원고와 `references.bib`, `figures/`를 함께 저장한다. 기존 ScholarPen 변환기를 사용하며, 같은 이름의 중첩 문서는 고유 이름으로 구분한다.
- 원본과 봉인된 회차를 수정하지 않는다. 매번 고유 폴더를 사용해 앞서 내보낸 결과와 원 프로젝트의 참고문헌을 보존한다. 회차 무결성 검사에 실패하면 내보내기를 중단한다.

## 검증

- 리뷰·파일 시스템·Markdown 변환 관련 78개 테스트 통과. JSON 바이트와 종속 파일 보존, 반복 내보내기, 그림 링크, 독립 참고문헌, 중첩 원고 이름, 잘못된 회차·변조 거절, 신규 프로젝트 폴더 생성 포함.
- TypeScript 검사 통과.
- 브라우저에서 실제 리뷰 화면의 JSON·Markdown·Quarto 선택 및 내보내기 요청, 기존 변환기의 원고 변환, 파일 목록 갱신 호출을 확인. 이 화면 검증의 저장 RPC는 임시 대체 함수이며, 실제 파일 저장은 위 백엔드 테스트로 별도 검증한다.
- 1.8.1 macOS arm64 배포 빌드 통과. 새 앱의 버전과 내보내기 코드 포함 여부를 확인하고, 압축 해제된 앱을 담은 버전명 DMG를 생성했다. 설치된 앱은 교체하지 않았다.

1.8.0 문서는 당시 구현 범위의 기록이다. 이 업데이트로 세션 화면에서 QMD/Markdown 원고 내보내기가 추가되었으며, DOCX/PDF 렌더와 페이지·행 매핑 등 다른 후속 기능은 변경하지 않았다.
