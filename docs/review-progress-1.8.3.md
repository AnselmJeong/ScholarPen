# ScholarPen 1.8.3 — 진행 상황과 저자 확인 항목

2026-10-26

## 진행 상황

Review & Revision에 현재 단계의 한국어 이름, 요청 모델, 현재 요청·이번 실행 경과 시간, 응답 수신 글자 수, 최근 응답 시각, 최근 완료 단계와 작업 기록을 표시한다. 2.5초 간격의 상태 확인과 1초 간격의 화면 시계를 사용한다. 최근 응답 수신은 실제 모델 출력이 전달될 때만 갱신하며, 내부 추론이나 원고 내용을 진행 정보로 전송하지 않는다.

앱 연결 확인과 모델 응답 수신을 구분한다. 연결 확인에 실패하거나 15초 이상 최신 상태를 받지 못하면 마지막 확인 상태라고 표시한다. 임의 완료율이나 남은 시간을 만들지 않는다. 요청당 기존 12분 제한을 안내한다. 기존 세션의 journal도 읽을 수 있으며, 실행 중에 잘못 나오던 ‘세션을 시작하면’ 문구를 수정했다.

## 확인이 필요한 제안은 보류하고 계속

수치·참고문헌 근거 또는 AI 수정안의 위치·기준 문장을 검증할 수 없으면 해당 제안을 적용하지 않고 원문을 유지한다. 다른 검증 가능한 수정은 계속한다. 보류 항목은 ID·위치·현재 원문·미적용 제안·제안 이유·검증 실패 이유를 저장하며 회차와 재개를 거쳐 유지한다.

해당 심사의견의 답변은 실제 적용 내역과 ‘저자 확인 필요’를 명시한다. 보류한 내용을 수정 완료로 보고하지 않도록 해당 답변을 실제 기록에서 구성하며, 요청한 영어·한국어를 따른다. 최종 답변서, unresolved-issues.md 및 author-checks.json에 남기고 최종 품질은 저자 확인이 필요한 상태로 표시한다. 외부 파일 변경·잘못된 원고 구조·인증 오류 등 안전한 진행이 불가능한 경우와 그림 승인 대기는 계속 중단한다.

## 검증

- 관련 회귀 테스트 88개 통과 후, 실제 응답 수신 상태를 확인하는 테스트를 추가해 리뷰 테스트 30개 통과(고유 테스트 89개).
- 숫자 제안을 보류하면서 다른 수정 완료, 공급자 오류 뒤 재개, 다음 회차에서 보류 항목 유지, 원문 보존, 최종 답변서에 확인 요청 포함을 검증했다.
- 사용자의 저장된 수정안 18개를 원본에 쓰지 않고 검사했다. 16개 적용 가능, P16과 P18은 저자 확인으로 분류했다. 실제 파일이나 실행 상태를 변경하지 않았다.
- TypeScript와 배포 빌드를 확인하고, 브라우저의 합성 세션으로 대기·수신·연결 실패 표시를 점검했다. 실제 설치 앱을 교체·재시작하거나 실제 모델을 호출하지 않았다.

새 버전을 설치한 뒤 해당 실패 세션에서 ‘저장된 단계부터 재개’를 사용할 수 있다. 기존 검토·수정 계획을 재사용하고 검증할 수 없는 제안은 확인 요청으로 넘긴다. 후속 답변서 작성·재검토에는 모델 호출이 필요하다.
