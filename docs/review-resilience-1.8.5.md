# ScholarPen 1.8.5 — 참고 자료 생성 중단 조건 점검

2026-10-26

## 원인과 처리 원칙

AI가 작성한 답변의 내용 검증 실패를 실행 오류로 처리해, 한 의견의 근거 누락 때문에 전체 세션이 중단됐다. 실제 사용자 세션의 저장된 답변 13개 중 R1-C01은 `clarified-no-change`인데 원고 위치가 없었다. 읽기 전용 재검사에서는 이 항목과 그림 후속 확인 항목을 저자 확인으로 전환한 후 13개 답변이 모두 통과했다. 사용자 원고나 세션 파일은 수정하지 않았다.

리뷰 결과는 참고용 자료다. AI 내용이 부족하면 확인 항목·미검토 범위를 명시하고 가능한 나머지 작업과 결과 파일 생성을 계속한다. 원고를 바꾸지 않은 제안이나 검증되지 않은 답변을 수정 완료로 보고하지 않는다.

## 점검한 중단 경로

| 경로 | 처리 |
| --- | --- |
| 수정하지 않는다는 답변에 위치·인용 근거 없음 | 미검증 초안과 확인 요청으로 전환 |
| 답변 누락·중복·빈 답변·알 수 없는 의견 ID | 원래 심사의견마다 확인 요청을 보장하고, 연결 불명 초안은 명시적으로 보관 |
| 적용하지 않은 변경 번호 인용·증거 없는 완료 주장 | 실제 변경 기록만 제시하고 초안의 주장은 미검증으로 분리 |
| 수정 계획의 의견 누락·중복·빈 판단 | 해당 의견을 저자 확인으로 남기고 유효한 수정 계속 |
| 수정 ID 중복·알 수 없는 의견 연결 | 모호한 수정만 미적용으로 남김 |
| 잘못된 그림 대상·중복 교체 요청·대체 파일 없음 | 원본 그림 유지, 답변서에 확인 요청 |
| 등록한 대체 이미지 누락·해시/승인 불일치 | 해당 교체만 보류하고 원본 유지 |
| 숫자·계산·참고문헌·원문 위치 검증 실패 | 해당 수정만 보류하는 기존 동작 유지 |
| GPT 재검토에서 의견 누락·중복·알 수 없는 ID | 누락 항목을 검증되지 않음으로 표시; 결과 생성 계속 |
| 미해결 확인 항목을 GPT가 검증 완료라고 판단 | 자동 완료로 승격하지 않고 확인 필요 유지 |
| 문맥 분석·가상 심사·그림 분석·계획·답변·재검토의 JSON/스키마 오류 | 형식 복구 최대 2회 후에도 실패하면 단계별 한계 기록; 보수적인 미검토 결과로 계속 |
| 저장된 형식 복구 횟수 소진 후 재개 | 호출 횟수를 초기화하지 않고 한계를 기록해 계속 |
| 모델 입력 예산 초과 | 원고를 자르거나 읽었다고 가장하지 않음; 해당 모델 단계를 미검토로 명시하고 원본이 포함된 참고 자료 생성 |
| 읽을 수 있지만 편집 구조가 불규칙한 문서 | 전문을 읽기 전용 참고 자료로 보존; 자동 수정 제외·검토 범위에 기록 |

전체 입력 예산 초과 시 자동 분석이 이뤄지지 않을 수 있다. 이 경우에도 결과를 검증 완료로 표시하지 않고 원본·확인 요청·자동 검토 한계를 담은 자료를 만든다. 복구되지 않은 원시 모델 출력은 세션 `.state/calls`에 보존된다.

## 계속 중단해야 하는 경우

사용자의 일시정지·취소, 인증·구독·모델 연결 실패 또는 요청 제한 시간, 저장 실패·디스크 공간 부족, 읽을 수 없는 원고 JSON, 원본 스냅샷/작업본의 외부 변경, 경로 이탈·동시 작성 충돌은 그대로 중단한다. 이는 AI 내용 부족과 달리 파일이나 실행 상태를 신뢰할 수 없거나 요청·저장이 실제로 불가능한 상황이다. 모델 형식 복구 처리에서 파일 쓰기 실패를 잘못 삼키지 않도록 예외 범위도 분리했다.

초기 스냅샷에서 미저장 원고·미결정 편집 제안을 확인하는 조건, 종료된 회차 편집 방지, 내보내기 대상·경로 검증은 실행 중 내용 검증과 구분해 유지했다.

## 결과와 화면

의견별 `author-checks.json`, 답변서, 미해결 항목에 확인 요청을 남긴다. 전체 단계의 한계는 `review-warnings.json`, 답변서, 품질 보고서와 공유 패키지에 포함한다. 경고가 있으면 최종 품질을 제출 준비 완료로 표시하지 않는다. 진행 화면과 계획·검증 탭에서도 자동 검토 한계를 표시한다. 구버전의 내용 검증 실패 세션에는 재개 방법을 안내한다.

## 검증과 배포

- 검토 테스트 54개, 273개 assertion 통과. 각 모델 단계의 잘못된 출력, 잘못된 답변·계획, 불완전한 평가, 그림 교체 실패, 불규칙 원고 구조, 큰 입력, 재개 및 원본 보존을 검사했다.
- 저장된 구버전 무수정 답변을 재사용해 추가 답변 호출·새 회차 없이 완료하는 테스트 통과. 한국어 확인 요청 포함.
- 실제 사용자 세션의 13개 답변을 읽기 전용으로 재검사했다.
- TypeScript 검사, 브라우저 합성 세션의 경고 표시, 배포 빌드 및 설치 이미지 무결성 확인.
- 설치 앱을 교체·재시작하지 않았고, 실제 모델이나 사용자 세션을 실행하지 않았다.

1.8.5를 설치한 후 기존 실패 세션에서 ‘저장된 단계부터 재개’를 사용한다. 남은 모델 단계에는 실제 모델 요청이 필요하다.
