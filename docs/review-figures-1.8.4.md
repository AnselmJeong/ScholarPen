# ScholarPen 1.8.4 — 그림 교체 때문에 검토가 멈추지 않도록 수정

2026-10-26

그림 교체 승인은 대체 이미지 생성이나 파일 등록을 수행하지 않는다. 이전 버전은 승인 후에도 대체 파일이 없으면 같은 대기 단계에서 다시 중단됐다.

이제 준비된 대체 파일이 없는 그림은 원본을 유지한다. 해당 수정 요청은 답변서와 author-checks.json에 미적용·저자 확인 필요로 남기고 나머지 검토와 최종 결과 생성을 계속한다. 적용하지 않은 그림 수정을 완료했다고 보고하지 않으며, 최종 품질은 저자 판단 필요로 표시한다. 등록된 대체 파일은 기존 승인·파일 무결성 검사 후 반영한다.

이전 버전의 그림 승인 대기 세션도 ‘저장된 단계부터 재개’로 계속할 수 있다. 기존 계획과 저장된 작업본을 재사용하며, 승인만 있고 대체 파일이 없는 경우에도 다시 그림 대기로 멈추지 않는다. 기존 세션 화면에 이 재개 방법을 안내하고, 교체 허용과 파일 선택 버튼을 구분했다. 완료된 회차는 원본 유지·수정 미적용 상태를 표시한다.

## 확인

- 검토 관련 테스트 31개, 140개 assertion 통과.
- 대체 파일 없이 완료, 원본·최종 그림 바이트 보존, 답변서에 미적용 명시, 기존 승인 대기 세션 재개, 실제 대체 파일 등록·반영 경로를 검증했다.
- TypeScript 검사 통과. 합성 세션을 띄운 브라우저에서 기존 중단 안내와 그림 확인 화면을 확인했다.
- 배포 빌드와 DMG 무결성을 확인했다. 현재 실행 중인 설치 앱과 실제 사용자 세션은 변경하지 않았다.

새 버전을 설치해야 새 동작이 적용된다. 재개 후 남은 답변 작성과 재검토에는 모델 호출이 필요하다.
