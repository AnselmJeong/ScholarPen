# ScholarPen 1.8.8 — 최신 답변서와 수정 원고 내보내기

2026-10-26

Review의 ‘의견과 답변’ 및 ‘답변서’는 완료된 세션에 연결된 `revisions/<session>/response.json`의 최신 답변을 읽는다. 이전에는 원고 편집 화면에서 저장한 답변과 별개로 봉인된 AI 결과를 읽고 있었다. 세션 원문과 자동 검토 기록은 그대로 유지하며, 저자 수정 답변은 별도로 표시한다. 답변 저장 중 Review를 열거나 내보내면 가장 최근 입력까지 저장이 끝나기를 기다린다. 저장 실패나 작업 답변서 손상·분실 시 오래된 AI 답변으로 대체하지 않는다.

‘전체 답변서 내보내기’는 장에 연결되지 않은 의견을 포함해 모든 reviewer 코멘트와 최신 답변을 원문 순서대로 묶는다. 루트 `exports/response-<session>-<id>/`에 Markdown, 인쇄/PDF 저장용 HTML, JSON을 저장한다. 자동 검토의 별도 경고·위치 정보는 제출용 답변 본문에 덧붙이지 않는다. 답변 자체에 남아 있는 AI 초안이나 저자 확인 문구는 임의로 삭제하지 않는다. HTML은 사용자 내용을 이스케이프하며 외부 자원을 요구하지 않는다.

‘최신 원고·답변서 내보내기’도 저장된 수정 원고와 최신 답변을 묶는다. 자동 검토 당시 변경표 등은 `automated-review/`에 구분하고, 수동 수정본을 검증 완료로 표시하지 않는다. 자동 검토 회차별 원고 내보내기는 별도 명칭으로 유지한다.

Explorer에서 수정 원고를 선택해 Markdown/Quarto로 내보내면 목적지는 원 프로젝트 루트의 `exports/`다. 읽는 본문과 그림은 수정본 기준이다. 그림은 루트 exports에 복사하고 경로를 재작성하므로 기존 Quarto 책 조판 경로에서 사용할 수 있다. 조판할 때에도 이미지 매핑을 따라 수정본 그림을 갱신한다. 수정본 참고문헌은 루트 참고문헌에 반영하되 루트에만 있는 항목을 유지한다. 동일 citekey는 수정본 항목을 사용한다. 교체되는 기존 출력 원고와 참고문헌은 `.scholarpen/export-backups/`에 내용 해시별로 보관한다. 원본 원고와 봉인된 reviews 자료는 수정하지 않는다.

검증: 관련 테스트 86개, 446 assertions 및 TypeScript 검사 통과. 임시 실제 파일에서 답변 저장·재열기·전체 내보내기, 저장 경합·오류, 원본 보존, 수정 원고의 루트 출력, 참고문헌 병합·백업, 그림 복사·조판 시 갱신, 경로 이탈 거절을 확인했다. React 화면은 합성 RPC로 직접 입력 → Review → 전체 답변서 표시와 내보내기를 확인했다. 파일 저장 경로는 별도 백엔드 통합 테스트에서 검증했다. 사용자 원고·세션은 수정하지 않았다.

macOS arm64 배포 빌드와 버전 1.8.8을 확인했다. 설치 이미지는 펼쳐진 앱을 포함한 `artifacts/ScholarPen-1.8.8-macos-arm64.dmg`이다. 기존 설치 앱을 교체하거나 재시작하지 않았다. 코드 서명·공증은 구성되어 있지 않다.

추가 실물 검증: 임시 수정본을 루트 `exports/`로 내보낸 뒤 실제 설치된 Quarto로 HTML과 Typst PDF를 렌더링했다. 수정 본문, 수정본 그림, 루트로 반영한 참고문헌 인용을 확인했고 `_book/Revision-export-verification.pdf` 생성에 성공했다. 테스트 입력에는 저자 정보와 유효한 SVG 그림을 사용했다. 최종 DMG는 `hdiutil verify`를 통과했으며 SHA-256 파일을 함께 생성했다.
