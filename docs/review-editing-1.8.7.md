# ScholarPen 1.8.7 — Explorer에서 원고 전환, 장별 답변 편집

2026-10-26

## 사용 흐름

Explorer의 `revisions/<세션>/documents/`에서 원하는 원고를 직접 연다. 수정본이면 왼쪽에 해당 원본이 읽기 전용으로 표시되고 오른쪽에서 수정본을 편집한다. 일반 원고를 열면 비교 화면을 해제한다. Review & Revision 화면이 열려 있을 때 Explorer에서 파일을 선택해도 선택한 문서로 전환한다.

비교 화면의 ‘Explorer 열기’를 눌러 다른 원고를 선택할 수 있다. 별도 장 선택기를 추가하지 않았다. 새 수정본을 선택하면 Explorer를 다시 접어 문서 영역을 확보한다. 기존 심사 화면의 편집 버튼은 첫 문서를 여는 바로가기로 남아 있으며, 편집 진입에 필수인 것은 아니다.

오른쪽 문서 영역에 ‘수정 원고 / 답변서’ 탭을 제공한다. 답변서는 현재 장에 연결된 심사의견과 편집 가능한 답변을 표시한다. 위치가 특정되지 않은 의견은 별도로 펼쳐 볼 수 있다. AI 사이드바는 최초 AI 답변을 계속 참고할 수 있도록 유지하며 Activity, History, Project, Assistant도 보존한다.

## 저장

- 답변 입력을 멈추면 약 0.7초 뒤 자동 저장한다. 포커스 이동, ‘답변 저장’, Cmd/Ctrl+S로도 저장할 수 있다.
- `revisions/<세션>/response.json`과 `response-to-reviewers.md`를 함께 갱신한다. 봉인된 `reviews/`의 심사 기록과 원본은 수정하지 않는다.
- 여러 장에 연결된 동일 의견은 하나의 답변을 공유한다. 장이나 프로젝트를 바꾸더라도 진행 중인 저장과 입력 내용을 유지한다.
- 여러 의견을 동시에 저장해도 다른 의견의 변경을 덮어쓰지 않는다. 같은 의견의 외부 수정은 이전 값 비교로 감지한다.
- 저장 오류가 나면 입력 내용을 유지하고 재시도 버튼을 표시한다. 앱 하단도 Unsaved로 표시한다. 성공 전에 저장됐다고 표시하지 않는다.
- Markdown 답변서를 외부에서 직접 편집한 경우, 재생성하기 전에 기존 내용을 `.scholarpen/response-backups/`에 보관한다. 이 편집기는 JSON에 저장된 의견별 답변을 기준으로 한다.
- 사용자가 수정한 답변은 자동 검증 완료로 간주하지 않는다. 원고와 답변의 일치 여부는 저자가 확인한다.

## 검증 범위

검토·프로젝트 구조·경로·답변 초안 테스트 67개, 333 assertions 통과. 실제 임시 파일에서 답변 저장/재열기, Markdown 동기화, 원본 및 봉인 결과 불변, 동시 저장, 충돌 감지, Markdown 백업, 실패 후 재시도를 검사했다. TypeScript 검사와 배포 빌드를 통과했다.

실제 React/BlockNote UI에 합성 RPC를 연결한 브라우저에서 Explorer 직접 열기, Introduction/Discussion 전환, 일반 원고로 돌아가기, 원본 읽기 전용, 답변 편집 및 재방문, 저장 실패 표시와 재시도를 확인했다. 실제 모델 호출이나 사용자 원고·심사 세션 변경은 하지 않았다. 실행 중인 설치 앱도 교체하거나 재시작하지 않았다.

배포 파일: `artifacts/ScholarPen-1.8.7-macos-arm64.dmg`. 펼쳐진 앱을 담은 설치 이미지이며 서명·공증은 구성되어 있지 않다.
