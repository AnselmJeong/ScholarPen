# ScholarPen 1.8.6 — 같은 프로젝트에서 원본과 비교하며 수정

2026-10-26

## 편집 위치

심사 완료 후 편집할 사본은 `프로젝트/revisions/<세션 ID>/documents/`에 생성한다. 그림과 참고문헌도 이 작업 폴더에 함께 복사한다. 기존 완료 세션은 ‘수정 원고에서 계속 편집’을 처음 누르면 사본을 생성한다. 다시 누르면 같은 사본을 열며 사용자가 수정한 내용을 덮어쓰지 않는다. 별도 프로젝트를 등록하거나 전환하지 않는다.

`reviews/`는 원본 스냅샷과 실행 기록을 보존하는 내부 폴더이며 Explorer에서 숨긴다. `revisions/`는 Explorer에 표시하는 편집 작업 폴더다. 공유용 내보내기를 명시적으로 실행한 경우에만 `exports/`에 공유 패키지를 만든다. 이전 버전에서 만들어진 내보내기나 별도 프로젝트를 이동·삭제하지 않는다.

## 비교 화면

- 수정본을 열면 Explorer를 접고 문서 영역을 좌우로 나눈다. 왼쪽은 읽기 전용 원본, 오른쪽은 자동 저장되는 수정본이다.
- AI가 바꾼 문단은 원본과 수정본 양쪽에 표시한다. 원본은 편집기나 협업 저장에 연결하지 않는다.
- 오른쪽 AI 사이드바의 ‘심사 답변’에는 해당 장의 심사자 지적, AI 답변, 저자 확인 항목을 표시한다. ‘본문 위치’로 수정본의 관련 문단에 이동한다. 장이 바뀌면 원본과 답변도 함께 갱신한다.
- 원고 위치가 특정되지 않은 의견은 별도로 펼쳐 볼 수 있다. 다른 장에만 연결된 의견은 현재 장의 의견으로 표시하지 않는다.
- Activity, History, Project, Assistant 탭은 유지한다. 심사 답변 패널의 기본 폭은 320px이며 드래그로 조정할 수 있다. Explorer도 다시 펼칠 수 있다.
- 답변은 AI 검토 완료 시점의 기록이다. 사용자가 원고를 편집한 후에는 답변과 본문의 일치 여부를 직접 확인하도록 안내한다.

문서 저장·협업 상태·그림·참고문헌·AI 문맥은 열린 수정본의 작업 폴더를 사용한다. 프로젝트 루트의 원고와 봉인된 심사 결과는 그대로 보존한다.

## 검증

- 검토 및 프로젝트 구조·문서 경로 테스트: 62개 통과, 307 assertions.
- 원본 불변, 수정본 실제 파일 저장, 사본 재개 시 사용자 편집 보존, 장별 의견 연결, 그림·참고문헌 경로 확인.
- TypeScript 검사 및 배포 빌드 통과.
- 실제 React/BlockNote 화면에 합성 RPC 데이터를 연결한 브라우저에서 좌우 비교, Explorer 자동 접기, 장 전환, 본문 위치 이동, 사이드바 탭 유지, 수정본 저장 경로를 확인했다. 원본에는 편집 가능한 요소가 없다.
- 실제 모델 요청이나 사용자 심사 세션 변경은 하지 않았다. 실행 중인 설치 앱도 교체하거나 재시작하지 않았다. 설치 앱에서의 최종 확인은 업데이트 후 필요하다.

배포물은 앱이 펼쳐진 `ScholarPen-1.8.6-macos-arm64.dmg`이다. 코드 서명과 공증은 구성되어 있지 않다.
